# Ar-Raman Sooto Autocare – Backend 🔧⚙️

This is the backend service for the Ar-Raman Sooto Autocare application.  
It provides RESTful APIs for managing contact, bookings, and other server-side operations.

This backend is designed to work with the Ar-Raman Sooto Autocare frontend application.

---

## ✨ Features

- REST API for garage services
- Booking management
- API validation
- Environment-based configuration
- Secure and scalable architecture

---

## 🛠 Tech Stack

- Node.js
- Express.js
- nodemailer
- dotenv
- Git & GitHub
